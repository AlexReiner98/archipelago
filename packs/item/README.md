# item

Page side: one page per item, in the region `right` while the map shows, for the item `here.item`
names. Title and status, the fields it has (each one line, by its kind),
its note, and its links one line each; a link opens the item at its other
end. `inside` and `around` set the query to draw it with its parts or its
neighbours.

It only shows: nobody adds, links or edits items by hand. Agents change
the map through the items actions, and the page follows live.
