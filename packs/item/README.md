# item

Page side: one page per item, in `map.side`, for the item `here.item`
names. Title, status, the fields it has (by kind; "+ field" adds one), its
note, and its links one line each (click one to go there, × to unlink).
Below: link to an item by title, make a part, and draw it `inside` or
`around`. Every edit is an action: `items.set`, `items.link`,
`items.unlink`, `items.create`.
