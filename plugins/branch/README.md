# branch

A flavour of work on trial: work done on a git branch. A lane of parallel
work and the integration that merges lanes are both `branch`, told apart by
`kind` (`lane`, `integration`). It adds `branch`, `head`, `files`, `checks`
and `pr`; its statuses are work's.

The only flavour the move of the old map earned: lanes and integrations
carried these fields on nearly every item. Kept or dropped by its record,
like any trial.

Injects `types.define`.
